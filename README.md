# The Unfair Advantage: Practical AI Automation (UniFR Workshop Command Center)

Interactive, gamified, 7-module web application designed for the 4-hour workshop at the **University of Fribourg (UniFR)** (*Teach and Learn Together Days*).
Feel free to use the resources!

## ✨ Key Architectural Features
- **Strict Single-View Switching:** Left collapsible sidebar swaps between the 7 modules (`#view-1` to `#view-7`) with hash routing for seamless GitHub Pages compatibility.
- **Swiss-Safe PII Anonymizer & De-Masking Vault (`anonymizer.html`):** Standalone 100% client-side tool allowing researchers and faculty to safely mask names, student IDs, Swiss phone numbers, emails, and grant budgets before sending prompts to free LLMs, and restore the AI's response with a single click using a purely in-memory session key.
- **One-Click Copy Prompt & GAS Code Cards:** Includes syntax highlighting, `ALL CAPS` edit indicators, emerald glow state (`Copied! Ready to Paste ✓`), and micro-confetti feedback.
- **Interactive 5-Node Spreadsheet Bridge Pipeline:** Animated SVG/CSS pipeline diagram with live node inspector and packet simulation.
